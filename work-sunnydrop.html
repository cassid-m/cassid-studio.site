Sunny Drop 様

(Reference Price | ¥250,000)

ブランドの世界観（カラフルで心が弾むようなデザイン、子供がのびのびと着られる素材）を伝え、新規顧客の獲得とECサイトへの誘導を目的とする。
商品・使用シーンなど素早く情報を得ることで、「時短」と「安心感」を優先したデザイン制作をし、新規顧客・購入への獲得を得る。

View Design (Figma)

Target

忙しい中でも、子供とのおしゃれを楽しみたいと考えている。お子さんを持つ、20代後半〜30代のお母様へ。

ペルソナシート

Request

ブランドのキーカラーである、太陽のような明るい黄色、空のような水色を基調にしたい。
【テイスト】カラフルでポップ、そして温かみのある、親しみやすいイメージ。
【雰囲気】子供たちの無邪気な笑顔が想像できるような、やわらかく、幸せな雰囲気にしたい。

Production Period

【 Planning / Wire-Framing 】約15時間
【 Design 】約38時間（修正含む）

Font

若干の丸みを帯びた親しみやすさと視認性を両立させた、Zen Kaku Gothic New・Rubikをベースフォントに採用。
子ども向け商材であるため、子どもが書いたようなアクセントフォントとしてReenie Beanieを採用し、遊び心を視覚的に訴求。

Color

ブランドイメージのオレンジ・ブルーを中心に、テキストは視認性の高さと真面目なメッセージ性を高めるために、ブラック・ホワイトを使用。
楽しく、子どもらしさを感じるポップなカラーの組み合わせで、ブランドイメージを視覚的に訴求。
