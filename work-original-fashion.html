オリジナルファッションブランド 様

(Reference Price | ¥7,000)

SNS用ブランド宣伝用バナー。
【待っていろよ、夏】をコンセプトに制作。
新商品のプロモーションを待ち望んでいた既存のブランドファンや、新しい刺激のあるファッションを求めている新たなユーザーに向け、ブランドの既存のスタイルにとらわれないデザインを訴求。

Target

10〜20代の刺激のあるファッションを求めている方へ。

Request

・明るくポップではなく、都会的で洗練されたイメージ。
・ストリート・クール・エッジの効いたイメージ。

Production Period

【 Planning・Design 】約3時間（修正含む）

Software

Design Logic

・サマーセール＝ブルーカラーベースを使用し、ユーザーに視覚的に訴求
 ・CTAは夏らしさも感じ、ストリート性のあるライムを使用
 ・CTAテキストをブラックでなく、ブラックよりのネイビーを使用することで、既存にとらわれないが、真摯な姿勢を表現することでユーザーに不安に感じさせずにクリックする効果を得る。

Font

可読性の高いフォント(Noro Sans jp・Inter)を使用することで、SNS上でスクロールしても何が書いてあるかすぐに情報を取得し、その画面で動きを止めることで、クリックへ促す効果を演出。
